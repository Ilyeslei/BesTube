# BesTube

BesTube is a browser extension for Chromium-based browsers designed to fully customize the YouTube interface with custom themes, accent colors, and a clean visual experience.

---

## Features
- Visual Themes: Choose between Light, Dark, and Midnight (OLED) modes.
- Accent Colors: Personalize the interface with multiple color palettes (Pink, Winter, Apple, Peach, Summer).
- Quick Access: A smooth popup menu accessible directly while browsing YouTube.
- Lightweight & Fast: Runs efficiently without impacting page performance.
- Privacy-Focused: Zero data collection—everything runs 100% locally on your browser.

## Manual Installation (Developer Mode)

To install or test the latest release directly in your browser:

1. Download the latest `.zip` package from the **[Releases](../../releases)** section.
2. Extract the `.zip` archive into your preferred directory.
3. Open your browser (Edge, Chrome, Brave, Opera) and navigate to the extensions page (`edge://extensions/` or `chrome://extensions/`).
4. Enable **Developer mode** (toggle switch in the top right corner).
5. Click **Load unpacked** and select the extracted folder.
